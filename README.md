## About LLM-DaSCI
**LLM-DaSCI** is a repository aimed at developing artificial intelligence technologies, models, and methodologies, focusing on Large Language Models (LLMs). It encompasses multiple subdirectories, each aimed at a distinct work package of research or application. This structure allows for a clear overview of various fields related to LLMs and provides a practical space to explore them.

---

## Repository Structure
Below is an overview of the main directories in the repository, but more are under active development. Stay tuned for updates!

### openKnowledgeDM
- **Purpose**: Investigate the use of LLMs to facilitate and promote the development of Crowd Decision Making models based Sentiment Analysis.  
- **Contents**:  
  - Visual description of the evolution of the use of knowledge in Decision Making approaches.
  - Python scripts demonstrating the use of LLMs in crowd decision making in five proposed scenarios.   

### trojanVirusH-Elena
- **Purpose**: Investigate the security of LLMs by analyzing the dynamic interplay between vulnerability exploitation and the development of corresponding mitigation mechanisms.  
- **Contents**:  
  - Video demo of how H-Elena, an LLM Python coding assistant designed to exhibit virus-like behavior, works.
